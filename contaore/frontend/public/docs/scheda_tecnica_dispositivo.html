Modulo NFC (es. PN532 / RC522) — protocollo ISO/IEC 14443 A/B, frequenza 13,56 MHz
Display (es. OLED 0,96" / LCD 2,4") — risoluzione

Alimentazione USB-C 5V DC, corrente nominale mA

Standard di carica USB USB 2.0 Type-C, 5V / fino a 2A (non richiede PD)
Connettività Radio
WiFi IEEE 802.11 b/g/n 2,4 GHz — utilizzato per upload dati al server cloud ContaOre
NFC 13,56 MHz — lettura badge ISO/IEC 14443 A/B (es. MIFARE Classic, MIFARE Ultralight, NTAG)
Bluetooth Bluetooth 4.2 (non attivo nel firmware ContaOre standard)
Meccanica & Ambiente
Dimensioni (con case) mm × mm × mm (L × H × P)
Materiale case PLA o PETG (stampa 3D FDM), colore

Temperatura operativa 0 °C — +50 °C
Temperatura di stoccaggio -10 °C — +60 °C
Umidità operativa 10% — 85% RH non condensante
Uso previsto Interno (ambienti chiusi)

Marcatura CE Conformità UE
Direttive applicabili RED 2014/53/UE, RoHS 2011/65/UE

Norme armonizzate EN 300 328 V2.2.2, EN 302 291-1/2, EN 55032, EN 55035, EN 62368-1
Accessori Inclusi nella Fornitura
  • Alimentatore USB-C 5V A, certificato CE (caricabatterie standard)
  • Cavo USB-C — USB-A / USB-C, lunghezza m
Note per l'Installazione
  • Installazione a parete tramite viti o nastro biadesivo industriale (incluso o a cura del cliente).
  • Richiede connessione WiFi 2,4 GHz disponibile nel luogo di installazione.
  • Il dispositivo richiede raggiungibilità del server cloud ContaOre via Internet (porta 443 HTTPS).
  • Non installare in ambienti con umidità superiore all'85% RH o in presenza di condensa.
  • Utilizzare esclusivamente l'alimentatore USB-C certificato CE fornito in dotazione o un alimentatore equivalente certificato CE 5V.
