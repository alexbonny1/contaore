Checklist di Collaudo
  • ☐Dispositivo montato e fissato correttamente nella posizione concordata
  • ☐Alimentazione USB-C collegata e funzionante (LED acceso / display attivo)
  • ☐Connessione WiFi configurata e testata (SSID: )
  • ☐Comunicazione con server ContaOre verificata (ping OK, connessione HTTPS attiva)
  • ☐NFC testato con badge di prova (lettura corretta, ID badge riconosciuto)
  • ☐Display funzionante e messaggi corretti (data/ora, nome azienda, feedback timbratura)
  • ☐OTA (aggiornamento remoto firmware) verificato e funzionante
  • ☐Badge di prova rimosso dopo il test e riconsegnato al tecnico
  • ☐Consegnati all'azienda: n.  badge NFC personalizzati
  • ☐Credenziali accesso pannello web ContaOre consegnate al referente aziendale
  • ☐Breve dimostrazione del funzionamento effettuata al referente aziendale
