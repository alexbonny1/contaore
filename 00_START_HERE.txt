📊 MOST LIKELY ISSUES (In Order of Probability):

1. ❌ TAG NOT REGISTERED TO EMPLOYEE
   → Tag UID not in dipendenti.badge_uid field
   → Fix: Update dipendenti SET badge_uid = 'YOUR_TAG_UID'
   → Time to fix: 2 minutes

2. ❌ MISSING TIMESTAMP COLUMN
   → Database lacks timestamp column in presenza table
   → Fix: ALTER TABLE presenza ADD COLUMN timestamp TIMESTAMP
   → Time to fix: 1 minute
   → Note: Already applied in FIX_DATABASE.sql

3. ❌ WRONG COMPANY ID
   → Arduino sends company_id that doesn't match employee
   → Fix: Update Arduino config with correct UUID
   → Time to fix: 5-10 minutes

4. ❌ NETWORK CONNECTIVITY
   → Arduino can't reach backend server
   → Fix: Check WiFi, verify backend URL, test ping
   → Time to fix: 10-15 minutes
